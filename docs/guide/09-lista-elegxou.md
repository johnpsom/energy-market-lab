# Κεφάλαιο 9: Λίστα ελέγχου, γλωσσάριο, βιβλιογραφία

## Λίστα ελέγχου πριν εμπιστευτείς ένα σύστημα πρόβλεψης τιμής

### Δεδομένα
- [ ] Κάθε πηγή έχει καταγεγραμμένες μονάδες, ζώνη ώρας και ανάλυση.
- [ ] Οι ημέρες αλλαγής ώρας (23/25 ώρες) χειρίζονται σωστά.
- [ ] Τα κενά έχουν ρητή πολιτική (αφήνω, συμπληρώνω, απορρίπτω).
- [ ] Οι προβλέψεις (καιρός, φορτίο, ΑΠΕ) αποθηκεύονται ξεχωριστά από τις παρατηρήσεις.

### Features
- [ ] Για κάθε feature έχει γίνει το τεστ του gate closure.
- [ ] Τα κυλιόμενα στατιστικά έχουν `shift` ≥ 24 ώρες.
- [ ] Κανένα input δεν περιέχει την ίδια την τιμή που προβλέπεται (π.χ. spark spread).
- [ ] Όσα features προέρχονται από γειτονικές ζώνες έχουν καθυστέρηση.

### Μοντέλο
- [ ] Υπάρχει baseline (persistence) και το μοντέλο το ξεπερνά.
- [ ] Ο διαχωρισμός είναι πάντα χρονικός, ποτέ τυχαίος.
- [ ] Η βαθμονόμηση γίνεται σε σύνολο που δεν χρησιμοποιήθηκε στην εκπαίδευση.
- [ ] Τα quantiles ταξινομούνται, ώστε να μην διασταυρώνονται.

### Επαλήθευση
- [ ] Walk-forward (ή ισοδύναμο) αντί για μία μόνο διαίρεση.
- [ ] Αναφέρονται MAE, bias, κάλυψη και skill, όχι ένας δείκτης μόνος του.
- [ ] Δεν βαθμολογούνται ημέρες που δεν έχουν συμβεί.
- [ ] Ο καιρός του ιστορικού είναι γνωστό αν είναι πρόγνωση ή reanalysis, και το όριο αυτό
  δηλώνεται.

### Εξήγηση και λειτουργία
- [ ] Οι κυριότεροι παράγοντες εμφανίζονται σε ανθρώπινη γλώσσα.
- [ ] Τα σενάρια ξαναϋπολογίζουν τα παράγωγα features.
- [ ] Η ακολουθία είναι idempotent και αφήνει log.
- [ ] Υπάρχει παρακολούθηση φρεσκάδας δεδομένων και κυλιόμενης κάλυψης.

## Γλωσσάριο

| Όρος | Σημασία |
|---|---|
| **Day-ahead (DAM)** | Δημοπρασία όπου σχηματίζονται οι τιμές της επόμενης ημέρας |
| **Gate closure** | Προθεσμία υποβολής προσφορών |
| **Merit order** | Κατάταξη σταθμών από τον φθηνότερο στον ακριβότερο |
| **Marginal pricing** | Η τιμή ορίζεται από τον τελευταίο σταθμό που χρειάστηκε |
| **Residual load** | Φορτίο μείον αιολικά και φωτοβολταϊκά |
| **Spike** | Απότομα υψηλή τιμή |
| **SRMC** | Βραχυπρόθεσμο οριακό κόστος παραγωγής |
| **HDD/CDD** | Βαθμοημέρες θέρμανσης/ψύξης |
| **ΑΠΕ** | Ανανεώσιμες πηγές ενέργειας |
| **Data leakage** | Χρήση πληροφορίας που δεν ήταν γνωστή τη στιγμή της πρόβλεψης |
| **Quantile regression** | Μοντέλο που προβλέπει συγκεκριμένο ποσοστημόριο της κατανομής |
| **Pinball loss** | Συνάρτηση απώλειας για quantile regression |
| **Conformal prediction** | Μέθοδος που βαθμονομεί διαστήματα ώστε να πιάνουν τον στόχο |
| **Coverage** | Ποσοστό πραγματικών τιμών μέσα στο διάστημα |
| **Walk-forward** | Έλεγχος με διαδοχική επανεκπαίδευση και πρόβλεψη του επόμενου μπλοκ |
| **Skill** | Βελτίωση απέναντι στη βάση σύγκρισης |
| **Persistence** | Βάση σύγκρισης: η τιμή της χθεσινής ίδιας ώρας |
| **Brier score** | Μέτρο ακρίβειας πιθανοτήτων |
| **SHAP** | Κατανομή της πρόβλεψης στη συνεισφορά κάθε feature |
| **Idempotent** | Λειτουργία που δίνει το ίδιο αποτέλεσμα όσες φορές κι αν τρέξει |
| **Drift** | Μεταβολή των σχέσεων των δεδομένων με τον χρόνο |
