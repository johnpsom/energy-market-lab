# Οδηγός: Πώς προβλέπεται η τιμή του ρεύματος

Ένας πρακτικός οδηγός για το πώς φτιάχνεται, από το μηδέν, ένα σύστημα πρόβλεψης της
ωριαίας τιμής ηλεκτρικής ενέργειας στη χονδρεμπορική αγορά της επόμενης ημέρας
(day-ahead). Κάθε κεφάλαιο έχει γραφτεί ώστε να γίνει ένα αυτόνομο άρθρο.

## Για ποιον είναι
Για αναλυτές, μηχανικούς και προγραμματιστές που ξέρουν βασική Python και στατιστική και
θέλουν να καταλάβουν ολόκληρη τη διαδικασία: από το τι κινεί την τιμή μέχρι το πώς ελέγχεται
αν η πρόβλεψη λέει αλήθεια.

## Ο χάρτης της διαδικασίας

```
 Αγορά & φυσική        Δεδομένα           Αποθήκη          Features
 (Κεφ. 1)         →    (Κεφ. 2)      →    (Κεφ. 3)    →    (Κεφ. 4)
                                                               │
 Λειτουργία &     ←    Εξήγηση       ←    Επαλήθευση   ←    Μοντέλο
 dashboard             (Κεφ. 7)           (Κεφ. 6)          (Κεφ. 5)
 (Κεφ. 8)
```

| Κεφ. | Τίτλος | Ερώτηση που απαντά |
|---|---|---|
| 1 | Η αγορά και τι κινεί την τιμή | Γιατί η τιμή είναι τόσο ασταθής; |
| 2 | Πηγές δεδομένων | Από πού παίρνω αξιόπιστα δεδομένα; |
| 3 | Η αποθήκη δεδομένων | Πώς τα αποθηκεύω ώστε να μην χαλάσουν; |
| 4 | Feature engineering | Πώς μετατρέπω δεδομένα σε σήματα για το μοντέλο; |
| 5 | Το μοντέλο πρόβλεψης | Πώς προβλέπω τιμή και αβεβαιότητα; |
| 6 | Επαλήθευση | Πώς ξέρω ότι η πρόβλεψη είναι καλή; |
| 7 | Εξήγηση | Γιατί προβλέπεται αυτή η τιμή; |
| 8 | Λειτουργία και dashboard | Πώς το τρέχω κάθε μέρα; |
| 9 | Λίστα ελέγχου, γλωσσάριο, βιβλιογραφία | Τι πρέπει να θυμάμαι; |

## Οι τρεις αρχές που διατρέχουν όλα τα κεφάλαια

1. **Μόνο ό,τι είναι γνωστό πριν το κλείσιμο της δημοπρασίας.** Η δημοπρασία της ημέρας D
   κλείνει το μεσημέρι της D-1. Κάθε στοιχείο που δεν ήταν γνωστό εκείνη τη στιγμή και
   χρησιμοποιείται στην εκπαίδευση ή στον έλεγχο λέγεται *διαρροή δεδομένων* (data leakage)
   και κάνει το σύστημα να φαίνεται καλύτερο απ' ό,τι είναι.
2. **Η πρόβλεψη είναι κατανομή, όχι ένας αριθμός.** Ο χρήστης χρειάζεται να ξέρει πόσο
   αβέβαιη είναι η τιμή, και ιδίως πόσο πιθανά είναι τα ακραία γεγονότα.
3. **Η ακρίβεια μετριέται απέναντι σε μια απλή βάση σύγκρισης.** Ένα σφάλμα «20 €/MWh» δεν
   λέει τίποτα, αν δεν ξέρεις τι σφάλμα θα έκανε η απλούστερη δυνατή μέθοδος.

## Πρότυπο για κάθε άρθρο

Για να έχουν τα άρθρα ενιαία δομή, προτείνω:

1. **Το πρόβλημα:** μία παράγραφος με το τι δεν δουλεύει χωρίς αυτό το βήμα.
2. **Η ιδέα:** η βασική έννοια σε απλά λόγια, με ένα παράδειγμα.
3. **Η διαδικασία:** βήματα με τη σειρά, με μικρά αποσπάσματα κώδικα.
4. **Συχνά λάθη:** τι πάει στραβά και πώς το καταλαβαίνεις.
5. **Άσκηση:** κάτι που ο αναγνώστης μπορεί να δοκιμάσει.
6. **Πρόσθετη ανάγνωση.**

## Σημείωση για τα παραδείγματα κώδικα
Τα αποσπάσματα είναι σύντομα και εικονογραφικά (Python, pandas, LightGBM). Δείχνουν την
ιδέα και δεν είναι πλήρες πρόγραμμα. Οι αριθμοί σε πίνακες και παραδείγματα είναι ενδεικτικοί
και όχι μετρήσεις συγκεκριμένης αγοράς.
