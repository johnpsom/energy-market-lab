# Κεφάλαιο 2: Πηγές δεδομένων

## Το πρόβλημα
Το μοντέλο είναι τόσο καλό όσο τα δεδομένα του. Χρειάζονται τέσσερις οικογένειες δεδομένων,
που έρχονται από διαφορετικές πηγές, με διαφορετική ανάλυση, ώρα και αξιοπιστία.

## Οι τέσσερις οικογένειες

### 1. Δεδομένα αγοράς και δικτύου (ENTSO-E Transparency Platform)
Η ευρωπαϊκή πλατφόρμα διαφάνειας, όπου οι διαχειριστές δικτύων δημοσιεύουν δεδομένα
υποχρεωτικά. Η πρόσβαση είναι δωρεάν με προσωπικό token (αίτημα με email στην ομάδα
υποστήριξης και δημιουργία κλειδιού στο προφίλ).

| Δεδομένο | Χρήση |
|---|---|
| Τιμές day-ahead | Ο στόχος και η πηγή των ιστορικών τιμών |
| Φορτίο (πραγματικό και πρόβλεψη) | Η πρόβλεψη φορτίου είναι δημοσιευμένη πριν την ημέρα, άρα νόμιμη είσοδος |
| Παραγωγή ανά τεχνολογία | Ιστορικό για να μάθεις τη σχέση ΑΠΕ → τιμή |
| Πρόβλεψη αιολικών/φωτοβολταϊκών (day-ahead) | Η πραγματική είσοδος για πρόβλεψη, γιατί η πραγματική παραγωγή της αυριανής ημέρας δεν υπάρχει ακόμα |
| Τιμές γειτονικών ζωνών | Επίδραση των εισαγωγών |

### 2. Καιρός
Θερμοκρασία, υγρασία, ταχύτητα και διεύθυνση ανέμου στο ύψος των ανεμογεννητριών (π.χ. 100
μ.), ηλιακή ακτινοβολία, νέφωση. Πηγές όπως το Open-Meteo δίνουν δωρεάν πρόγνωση και
ιστορικό. Επιλέγεις **αντιπροσωπευτικά σημεία**: ένα ανά μεγάλο κέντρο ζήτησης και ένα ανά
περιοχή με ανεμογεννήτριες ή φωτοβολταϊκά, και όχι έναν μέσο όρο της χώρας.

### 3. Καύσιμα και άνθρακας
Ημερήσιες τιμές κλεισίματος για φυσικό αέριο (TTF), δικαιώματα εκπομπών CO₂ (EUA) και
πετρέλαιο. Δίνουν το **επίπεδο** της τιμής, ενώ ο καιρός και το ημερολόγιο δίνουν το σχήμα.

### 4. Ημερολόγιο
Αργίες, Σαββατοκύριακα, ώρες αιχμής. Δεν χρειάζεται εξωτερική πηγή, μόνο μια βιβλιοθήκη
αργιών.

## Προβλέψεις έναντι παρατηρήσεων: η πιο σημαντική διάκριση
Για κάθε μέγεθος μπορεί να υπάρχουν δύο εκδοχές:

- **Πρόβλεψη**, όπως δημοσιεύθηκε πριν από την ημέρα.
- **Παρατήρηση**, δηλαδή τι έγινε πραγματικά.

Στην παραγωγική χρήση θα έχεις μόνο προβλέψεις. Αν εκπαιδεύσεις και ελέγξεις το μοντέλο με
παρατηρήσεις, ο έλεγχος θα είναι υπερβολικά αισιόδοξος. Ο πιο συνηθισμένος τρόπος να
συμβεί αυτό χωρίς να το καταλάβεις είναι ο καιρός: τα ιστορικά αρχεία (reanalysis) δίνουν
τον πραγματικό καιρό, όχι αυτό που προέβλεπε η πρόγνωση. Ο ασφαλής δρόμος είναι να
**αρχειοθετείς κάθε πρόγνωση με την ώρα έκδοσής της**, ώστε με τον καιρό να χτιστεί
ιστορικό πραγματικών προγνώσεων (βλ. Κεφ. 3 για το «vintage»).

## Το σχέδιο ενός collector
Κάθε πηγή έχει μια μικρή ενότητα κώδικα με την ίδια δομή:

1. Μετατροπή των ημερομηνιών σε ώρα με ζώνη (timezone-aware).
2. Κλήση του API.
3. Ομογενοποίηση (το ίδιο όνομα στηλών, ίδιες μονάδες).
4. Μετατροπή σε **long format**: μία γραμμή ανά (χρόνος, διάσταση, τιμή).
5. Προσθήκη στηλών προέλευσης (`source`, `zone`).
6. Επιστροφή DataFrame έτοιμου για αποθήκευση.

```python
def fetch_prices(start, end, zone):
    s = pd.Timestamp(start, tz="Europe/Athens")
    e = pd.Timestamp(end,   tz="Europe/Athens")
    series = client.query_day_ahead_prices(zone, start=s, end=e)
    df = series.rename("value").rename_axis("ts").reset_index()
    df["zone"], df["product"], df["source"] = zone, "day_ahead", "entsoe"
    return df[["ts", "zone", "product", "source", "value"]]
```

## Παγίδες των δεδομένων

- **Μονάδες.** Ένα API που δίνει km/h ενώ η καμπύλη ισχύος περιμένει m/s δεν βγάζει σφάλμα,
  απλώς χαλάει σιωπηλά τα αποτελέσματα. Έλεγξε τις μονάδες ρητά.
- **Ώρα και αλλαγή ώρας.** Οι ημέρες με αλλαγή ώρας έχουν 23 ή 25 ώρες. Δούλευε με
  timestamps με ζώνη ή σε UTC και μετά μετέτρεψε.
- **Ανάλυση.** Οι αγορές μετακινούνται σε 15λεπτη ανάλυση, ενώ παλιότερα δεδομένα είναι
  ωριαία. Φέρε όλα στον ίδιο ρυθμό (π.χ. ωριαίος μέσος όρος).
- **Καθυστέρηση δημοσίευσης και αναθεωρήσεις.** Τα δεδομένα εμφανίζονται με καθυστέρηση και
  ορισμένα διορθώνονται αργότερα. Σημείωσε πότε ήταν διαθέσιμο κάθε δεδομένο.
- **Κενά.** Κάθε πηγή έχει κενά. Αποφάσισε ρητά τι κάνεις: αφήνεις το κενό (τα δέντρα
  αποφάσεων το δέχονται), συμπληρώνεις, ή απορρίπτεις τη γραμμή.
- **Ανεπίσημες πηγές.** Δωρεάν πηγές χωρίς εγγύηση διαθεσιμότητας (π.χ. τιμές καυσίμων μέσω
  μιας δημόσιας βιβλιοθήκης) είναι εντάξει για πείραμα, αλλά όχι για κρίσιμη χρήση.

## Άσκηση
Τράβηξε τις τιμές day-ahead μίας εβδομάδας για μία ζώνη. Έλεγξε πόσες γραμμές έχει κάθε
ημέρα και εξήγησε γιατί η ημέρα αλλαγής ώρας διαφέρει.
